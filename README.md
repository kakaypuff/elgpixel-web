# elgpixel.no

Public website for ElgPixel: the publisher home page, privacy policies and terms for each app and game, and `app-ads.txt`.

Do not edit these files by hand. They are generated from the WiFiRoom repository (`tool/publish_website.sh`), using `config/app_config.json` and `website/src/`.

Published with GitHub Pages (branch `main`, folder `/`) on the custom domain in `CNAME`.
